# Daily Current Affairs Bilingual PDF Studio (English & Hindi)

An interactive browser-based studio for reviewing, editing, adding custom images, and exporting **Daily Current Affairs** PDFs in both **English** and **Hindi (हिंदी)** matching the exact Physics Wallah / Banking Wallah two-column A4 publication layout.

## Why `index.html` is 100% Self-Contained (Zero Broken Links on GitHub Pages)

`index.html` has all styles, scripts, bilingual datasets, and base64 image assets bundled directly inside it. Even if you upload **only `index.html`** via GitHub's web uploader, the entire application, all 10 pre-loaded English & Hindi articles, the Page 1 Test-Pass promotional banners, and the dual PDF exporter will load and work immediately with zero missing file/folder issues.

## Quick GitHub Pages Setup (2 Minutes)

1. In your GitHub repository, click **Add file → Upload files**.
2. Drag and drop **`index.html`** (and optionally `README.md` and `.nojekyll`) into the root of your repository, then click **Commit changes**. *(If an older `index.html` is already in your repo, uploading this new `index.html` will automatically replace it.)*
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch** (`main` / `root`), and click **Save**.
4. Hard-refresh your live GitHub Pages URL (`Ctrl+Shift+R` on Windows or `Cmd+Shift+R` on Mac) after 60 seconds.
